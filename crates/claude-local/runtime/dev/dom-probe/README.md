# DOM 探针（开发用）

拓展的挂载点（输入框按钮、消息操作、侧栏入口、设置分区……）要挂在 Claude 页面的具体位置上，这些位置写在
`runtime/page-anchors.js` 里。Claude 改版后锚点可能失效，要重新量一遍：这个拓展包把页面的结构和原生控件的
计算样式存成文件，照着它改锚点表，锚点测试用的样本（`runtime/fixtures/dom/`）用 `dev/export-dom.js` 导出。

它只记结构和样式：标签、`data-testid`、`role`、`aria-label`、类名、属性名、位置大小、计算样式。不记文字内容；
属性值只记形状（`<uuid>`、`<number>`、短标识），地址里的会话 id 换成 `:uuid`。

## 用法

1. 在 ClaudeMom 的「扩展」页（或 Codex++「万物皆拓展」的 Claude 页签 → 导入扩展包）导入这个文件夹里的
   `codexpp.json`，打开它的开关。它带后台（用来写文件），启用时会确认一次。
2. 启动 Claude，或刷新 Claude 页面。加载 6 秒后会自动存一份。
3. 依次切到要量的页面，各存一份：按 `⌘⌥⇧D`（Windows 是 `Ctrl+Alt+Shift+D`），或点右下角悬浮按钮里的
   「DOM 探针」→「保存当前页面结构」。建议量这些：
   - Chat：新对话的首页；一条有来有回的对话；鼠标停在一条消息上（操作行出现）时。
   - Cowork、Code：各自的首页，和一个进行中的会话（最好有工具调用、有等审批的卡片）。
   - 设置页。
   - 侧栏展开和收起各一次；会话行的「更多」菜单、模型选择器点开时各一次。
   - 登录账号的界面（`claude.ai`）和本机版界面（`app://localhost`）结构可能不同，两种都能进的话各量一遍。
   也可以让它自己走一遍：悬浮按钮里点「自动巡览」，或在配置里打开「启动后自动巡览」（每个窗口第一次加载时开始）。
   它依次整页打开 Chat 新对话、第一个对话、Cowork、第一个 Cowork 会话、Code、第一个 Code 会话、设置，
   每页加载好 9 秒后存一份（文件名带 `tour-<步骤>`）；当前页面上找不到「第一个会话」的链接时跳过那一步。
4. 文件在拓展的数据目录里：`<状态目录>/claude-local/extension-data/dom-probe/dump-<时间>-<页签>-<原因>.json`。
   ClaudeMom 的状态目录是 `~/.claude-mom`，Codex++ 是它自己的状态目录。

每份文件的 `fixture` 字段和 `dev/export-dom.js` 导出的样本同一格式，取出来就能放进 `runtime/fixtures/dom/`。

量完把开关关掉即可。
