# Журнал изменений

**[English](CHANGELOG.md) · [简体中文](CHANGELOG.zh-CN.md) · [Русский](CHANGELOG.ru.md)**

## 0.1.6 - 2026-11-16

- Заголовки диалогов в Chat и Cowork теперь генерирует модель апстрима — вместо безликого «New task» или пустоты; диалоги можно переименовывать и удалять.
- Починено: часть запросов Chat теряла текст вопроса после сжатия.
- Windows: починена диктовка, которая не подключалась (голосовой сервис отдавал 503).
- Починена ошибка «Invalid BFF response format» при отправке задачи в Cowork.
- Починена ошибка Artifacts «policy check couldn't get through».
- Локальный сервис теперь предпочитает системный Node.js (22+), а не тот, что тащится с ChatGPT / Codex; откат к ним — только если системная версия слишком старая.

## 0.1.5 - 2026-11-16

- Починено «не удалось скачать Claude Code (IDLE_TIMEOUT)» при первом запуске Code / Cowork: большие файлы теперь конвертируются по ходу загрузки, а не читаются целиком в память (при скачивании память больше не раздувается до нескольких гигабайтов).
- Починено «связь с ответом Claude прервалась» сразу после отправки в Chat: если апстрим ошибается (неверный Key, несуществующая модель, нестандартный ответ шлюза и т.п.), его причина теперь показывается прямо в ответе; шлюзы с CRLF-разделителями, без конечных событий и без стриминга тоже поддержаны.
- Windows: починено сообщение «управление компьютером не включено для вашего аккаунта» при включении Computer Use в настройках.
- Windows / macOS: если другой пользователь той же машины держит Claude открытым, он больше не считается вашим и не висит с вечным «запущено».
- Починены пустые сообщения при открытии существующего диалога.
- Встроенные примеры навыков (в локальном режиме не скачиваются) больше не показываются включёнными, и Claude перестал при каждой синхронизации пытаться их скачать и репортить провал.

## 0.1.4 - 2026-11-16

- Починено открытие тысяч соединений локальным сервисом при первом запуске Claude (в прокси и файрволах видно кучу node-соединений): запросы к апстриму теперь делят соединения и ограничивают конкурентность.
- Починено: при свежей установке интерфейс мог получить другую раскладку, а вкладка Code — вечно грузиться; первый запуск больше не требует прямого доступа к claude.ai — меньше «Couldn't connect to Claude / Bad Gateway».
- Когда Claude закрывает соединение, локальный сервис закрывает и своё — соединения больше не копятся; соединения к прочим доменам (статистика, отчёты об ошибках) тоже идут через системный прокси.
- В Настройки → Дополнительно добавлен пункт «Использовать встроенный интерфейс машины (экспериментально)» — выключен по умолчанию, пока только для тестов.

## 0.1.3 - 2026-11-15

- Windows: починено — в новых сборках десктопа Claude на главной странице не было переключателя «Чаты | Cowork»; теперь Cowork открыт по умолчанию. Не нужен — отключите в Настройки → Дополнительно → Cowork.
- В некоторых версиях Claude нет `ion-dist.asar` — интерфейс распакован в каталог; из-за этого локальный сервис не запускался и бесконечно показывал «локальный сервис не запущен». Теперь поддерживаются оба варианта.

## 0.1.2 - 2026-11-13

- Импорт из cc-switch: читаются и провайдеры, настроенные отдельно для десктопа Claude (страница «Claude Desktop» в новых версиях cc-switch); одинаковые пары адрес + Key импортируются только один раз.
- Импорт из cc-switch: база данных ищется по правилам самого cc-switch — находится даже при переопределённом в его настройках каталоге конфигурации.
- Если в cc-switch есть только провайдеры формата OpenAI, теперь объясняется причина, а не сухое «не найдено».

## 0.1.1 - 2026-11-12

- macOS: Claude запускается через систему (LaunchServices), поэтому права доступа — запись экрана, универсальный доступ и другие — считаются самим Claude и больше не показываются как «не запрошены».
- В Настройки → Дополнительно добавлен переключатель «Включать фоновый режим на новых системах» (выключен по умолчанию): если Claude на свежем macOS пишет «фоновый режим пока не поддерживается», он снимает ограничение по версии системы. Claude это не валидировал — возможна нестабильность.

## 0.1.0 - 2026-11-12

Первый релиз: самостоятельная программа, выделенная из CodexPlusPlus.

- Полнофункциональный режим оригинального десктопа Claude (Chat / Code / Cowork, китайский интерфейс) с прямым подключением к вашему апстриму (Base URL + Key).
- Несколько апстримов с мгновенным переключением; импорт провайдеров Claude из cc-switch или локальные шлюзы Magpie / Codex++ как апстрим.
- Локальная диктовка (SenseVoice, офлайн-распознавание).
- Автообновление.
